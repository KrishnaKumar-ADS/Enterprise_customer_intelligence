## Local Storage Policy

data/raw contains source-derived data exports.
Do not manually edit or clean raw data.

data/processed contains normalized data generated by this project's code.

## Important Data Characteristics

- One source row represents an invoice line item.
- An invoice can contain multiple line items.
- Invoice numbers beginning with C indicate cancellations.
- Negative quantities may represent returns.
- Customer IDs can be missing.
- Unit prices are denominated in GBP.
- The dataset does not provide official customer churn labels.
- An unusual transaction is not automatically fraudulent.

## Target Definition Limitations

Churn must be defined from customer inactivity in a future window.
That target will be a proxy, not a confirmed cancellation label.

Future customer value will be calculated from transactions in a defined
90-day outcome window.

All model features must use only information available at the
prediction timestamp.
